# Smart-Campus-Cafeteria-Tracker-
A data analytics and frontend dashboard project tracking college cafeteria metrics .

## Project Overview 
This project bridges data management and frontend presentations.It features a robust SQL backend containing relational tables for MENU,Orders,and Feedback,
alongside an HTML-based analytics interface designed to present insights cleanly.

## Tech Stack  

* **Database:** SQL(MySQL)
* **Frontend:** HTML5

## Core Analytics Solved (SQL) 

I wrote specific queries to extract critical business metrics fom the cafeteria data:
1. **Revenue Generation:** Combined orders and menu pricing to calculate gross earnings.
2. **Peak Hour Analysis:** Isolated timestamp to pinpoint the exact hour of the highest traffic.
3. **Quality Assurance:** Filtered customer feedback to instantly flag dishes rating below 3 stars.

## Frontend Interface(HTML) ##
The accompanying dashboard includes:
* Metric cards highlighting key revenue data.
* Clean data tables presenting the results.
* Mock submission forms for inputting real-time orders entries.
